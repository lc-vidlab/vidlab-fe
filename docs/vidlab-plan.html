Vidlab: YouTube Data API 기반 영상 탐색 웹

YouTube Data API v3로 인기 영상 피드, 검색, 영상 상세(재생 · 댓글)를 구현하는 웹 프론트엔드 프로젝트입니다. YouTube와 같은 다크/라이트 모드를 지원하고, 4명이 영역을 나눠 약 3주 안에 데모 가능한 버전을 만드는 것이 목표입니다.

스택 Next.js (App Router) · React · TypeScript · TanStack Query · next-themes · Supabase(익명 댓글 저장, 확정 필요) 기간 3주 (W1~W3) 배포 Vercel 디자인 기준 Vidlab 디자인 샘플 (홈 피드 · 영상 상세)
02

범위

이번에 만드는 것

  • 홈: 국가별 인기 영상 피드, 카테고리 필터, 무한 스크롤
  • 검색: 키워드 검색, 결과 페이지네이션, 정렬 필터
  • 상세: 임베드 재생, 영상 · 채널 정보, YouTube 댓글 목록(읽기 전용)
  • 익명 댓글: 로그인 없이 닉네임 · 비밀번호 · 내용으로 작성하고, 비밀번호로 삭제. 자체 DB에 저장
  • 다크/라이트 모드, 시스템 설정 연동, 반응형

이번에 만들지 않는 것

  • 개인화 추천 피드: API로 제공되지 않음
  • 로그인 · 회원 기능, 좋아요
  • YouTube에 실제 댓글 등록: 익명 댓글은 Vidlab 안에만 보임
  • 영상 업로드, 구독 관리, 재생목록 편집
  • 대댓글, 댓글 수정
  • 자체 영상 호스팅 · 스트리밍 서버
  • 싫어요 수 표시: 2021년부터 비공개

화면 · 기능 정의

화면 (경로) 주요 기능 상태 처리 담당
공통 레이아웃 헤더(로고 · 검색창 슬롯 · 테마 토글), 사이드 메뉴, 다크/라이트 토큰 테마 첫 렌더 깜빡임 방지, 모바일에서 사이드 메뉴 접기 이주혁
홈 피드 / 인기 영상 그리드, 카테고리 칩, 무한 스크롤 첫 로딩 스켈레톤, 추가 로딩, 마지막 페이지, 에러 재시도 주훈
검색 결과 /results?q= 헤더 검색창, 결과 리스트, 더 보기, 정렬 · 기간 필터, 최근 검색어 결과 없음, 할당량 초과 안내, 중복 요청 방지 민진
영상 상세 /watch/[id] IFrame 플레이어, 제목 · 채널 · 설명, 댓글 탭(Vidlab 댓글 / YouTube 댓글), 익명 댓글 작성 폼(닉네임 · 비밀번호 · 댓글창), 비밀번호로 삭제, 관련 영상 YouTube 댓글 비활성화, 임베드 불가 · 연령 제한, 입력 검증 오류, 비밀번호 불일치, 작성 제한 초과 수현
익명 댓글 API /api/comments 댓글 조회 · 작성 · 삭제, 비밀번호 해시 저장, 스팸 방지 입력 검증, 비밀번호 불일치, 요청 횟수 제한 이주혁
05

API 매핑 · 할당량

기본 할당량은 프로젝트당 하루 search.list 100회와 그 외 호출 합산 10,000유닛입니다. 한국 시간 오후 5시(서머타임 기간에는 오후 4시)에 초기화됩니다. 모든 호출은 Next Route Handler를 거치며, 클라이언트에 API 키를 노출하지 않습니다.

기능 엔드포인트 비용 인증 사용처
인기 영상 피드 videos.list?chart=mostPopular&regionCode=KR 1 API 키 주훈
카테고리 목록 videoCategories.list?regionCode=KR 1 API 키 주훈
키워드 검색 search.list?type=video 검색 1회 API 키 민진
검색 결과 보강 (재생시간 · 조회수) videos.list?id=…(최대 50개) 1 API 키 민진
영상 상세 videos.list?id= 1 API 키 수현
채널 정보 channels.list?id= 1 API 키 수현
YouTube 댓글 목록 (읽기 전용) commentThreads.list?videoId= 1 API 키 수현
Vidlab 댓글 목록 GET /api/comments?videoId=&cursor= 자체 DB 없음 수현 · 이주혁
Vidlab 댓글 작성 POST /api/comments 자체 DB 없음 (닉네임 · 비밀번호 입력) 수현 · 이주혁
Vidlab 댓글 삭제 DELETE /api/comments/[id] 자체 DB 작성 시 비밀번호 수현 · 이주혁
영상 재생 IFrame 임베드 플레이어 0 없음 수현

  page.tsx                 홈 피드 (주훈)

  ui/                      Button, Skeleton, EmptyState
  video/                   VideoCard (주훈, 공용)
features/
  feed/  search/  watch/   영역별 훅 · 컴포넌트
lib/
  youtube/                 API 클라이언트 · 타입
  db/                      DB 클라이언트 · 댓글 스키마
  format.ts                조회수 · 기간 · 재생시간
mocks/                     API 응답 fixture

규칙

  • W1 수요일까지 lib/youtube/types.ts와 Route Handler 응답 형태를 이주혁이 확정합니다. 이후 각자 mock으로 개발합니다.
  • USE_MOCK=true가 기본값입니다. 실제 API는 개인 GCP 프로젝트 키로만 테스트하고, 팀 키는 배포에만 씁니다.
  • 브랜치는 feature/{영역}-{기능} 형식이며, PR마다 리뷰어 1명 이상 승인 후 머지합니다.
  • 색상은 CSS 변수 토큰만 사용합니다. 하드코딩한 색은 리뷰에서 반려합니다.
  • 공용 컴포넌트(VideoCard, Skeleton)를 수정할 때는 PR에 다른 담당자를 리뷰어로 추가합니다.

09

리스크 · 제약

항목 내용 대응
검색 할당량 프로젝트당 하루 100회로, 팀 전체가 같이 쓰면 금방 소진됩니다. mock 기본, 개인 GCP 키, 제출 시에만 호출, 서버 캐싱(1시간)
익명 댓글 구조 YouTube API는 로그인 없이 댓글을 쓸 수 없습니다. 그래서 익명 댓글은 자체 DB에만 저장되고 YouTube에는 올라가지 않습니다. 탭으로 "Vidlab 댓글"과 "YouTube 댓글"을 나누고, 작성 폼에 "Vidlab에서만 보이는 댓글"이라고 표시합니다.
익명 댓글 남용 로그인이 없어서 도배, 욕설, 광고 댓글에 취약합니다. IP 기준 작성 횟수 제한, 금칙어 필터, 숨김 필드, 관리자 삭제 수단을 둡니다.
비밀번호 · 개인정보 댓글 비밀번호와 IP를 그대로 저장하면 유출 시 문제가 됩니다. 비밀번호는 bcrypt 해시로, IP는 솔트 해시로만 저장하고 응답에 절대 포함하지 않습니다.
관련 영상 search.list의 관련 영상 파라미터(relatedToVideoId)가 제거되었습니다. 같은 카테고리의 인기 영상으로 대체합니다(1유닛).
재생 제한 임베드 비허용, 연령 제한, 지역 제한 영상은 플레이어에서 재생되지 않습니다. 목록에서 status.embeddable로 거르고, 상세에는 "YouTube에서 보기" 링크를 둡니다.
YouTube 댓글 비활성 댓글이 막힌 영상은 403 commentsDisabled를 반환합니다. YouTube 댓글 탭만 안내 문구로 대체합니다. Vidlab 댓글은 그대로 쓸 수 있습니다.
약관 · 브랜딩 YouTube 이름 · 로고를 서비스명으로 쓸 수 없고, API 데이터는 장기 보관하면 안 됩니다. 서비스명은 Vidlab(가칭)을 쓰고, 캐시는 짧게(분~시간 단위) 유지합니다.

확인 필요

  • W1 시작일과 데모일
  • 디자인 기준을 Vidlab 샘플로 확정할지, 담당자별로 다듬을지
  • Next.js 버전과 React Query 사용 여부 최종 확정 (이주혁, W1 첫날)
  • 댓글 DB: Supabase(Postgres)와 Neon 같은 다른 선택지 중 확정 (이주혁, W1)
  • 익명 댓글 운영 정책: 금칙어 범위, 관리자 삭제 담당자
  • 배포 도메인, Vercel 팀 계정 소유자
  • 코드 리뷰 방식: 영역별 페어(주훈↔민진, 수현↔이주혁) 여부
